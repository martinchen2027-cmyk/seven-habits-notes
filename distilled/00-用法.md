# 怎么用这套蒸馏稿分析问题

书是《高效能人士的七个习惯》30周年纪念版。下面各文件按这一本的小标题写。小标题都在。用来判断他的问题落在哪，不代替他做选择。

## 先分清问题在哪一层

1. **看世界的方式错了**（第一部分）：他很努力，但梯子靠错墙；用技巧压关系；怪别人。
2. **自己还站不稳**（习惯一、二、三）：被情绪拖着走、不知道要什么、忙但不是要事。
3. **人和人之间**（第六章到习惯六）：信任不够、总想赢过对方、还没听懂就给办法、差异变成对立。
4. **人被耗干了**（习惯七）：身体、精神、头脑、关系里有一块长期透支。

顺序不要倒。公众领域的成功以个人领域的成功为底。关系技巧补不上品德和方向的亏空。

## 每次分析都走这几问

1. 刺激来了，他有没有选择怎么回应，还是已经把原因全部放在外面？
2. 这件事和他真正想成为的人、想留下的评价，是同一方向还是相反？
3. 它重要吗？紧急吗？是第二象限被拖着没做，还是别人的紧急？
4. 信任账户是在存还是在取？他要的是双赢，还是赢过对方？
5. 他听懂对方了吗，还是在用自己的经历回答？
6. 有没有第三条路，还是只在「你对我错」里选？
7. 四个更新层面有没有一块已经亏空，所以别的习惯做不动？

回答时写明用的是哪一节。可以多写判断过程。不要把整本书一次性倒给他，把能解释眼前这个问题的节写透。
