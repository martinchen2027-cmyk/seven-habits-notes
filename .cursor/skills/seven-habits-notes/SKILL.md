# 七个习惯：用来分析问题

蒸馏稿在本项目 `distilled/`。回答前先读 `distilled/00-用法.md`，再读和这个问题有关的章节文件。

他不会自己去翻这些稿。你用稿子帮他看问题，回答可以长，要能拿来判断，不要只丢结论。

## 他若明确说「按我的划线 / 批注」并给了照片

只写红线底下的原句和他页边上的字。没划的邻段不要写。这是例外，不是默认。

## 默认：拿问题来问

按 `distilled/00-用法.md` 的顺序分析。先私人领域（习惯一、二、三），再公众领域（习惯四、五、六），最后看要不要习惯七。说明用的是书里的哪一节，不要把没读到的文件说成他的笔记。
